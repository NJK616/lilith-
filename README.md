# lilith升学

大学生升学规划助手 —— 帮你在大一到大四每个阶段，找到最适合的升学路径。

## 功能

- **问卷评估**：填写年级、院校、专业、GPA、英语水平等信息，系统智能推荐路线
- **四条主路线**：就业、考研、考公/选调、出国留学，每条路线覆盖大一到大四的完整学期任务
- **专业差异化**：不同专业在每个路线上的推荐度不同，基于真实就业数据
- **院校层次识别**：自动识别 985/211/双一流/普通本科，调整路线评分
- **转专业规划**：大一用户可设置转专业目标，任务自动适配
- **任务追踪**：每学期任务可勾选完成，随时查看进度
- **AI 升学顾问**：基于你的个人信息，实时解答升学疑问
- **账号体系**：支持邮箱注册/登录、游客登录、头像修改

## 技术栈

- Flutter 3.x (Dart)
- 本地账号系统 (SharedPreferences)
- 本地数据驱动 (专业数据库 / 院校数据库 / 路线规划)

## 构建

```bash
flutter pub get
flutter build apk --release
```

APK 输出路径：`build/app/outputs/flutter-apk/app-release.apk`
